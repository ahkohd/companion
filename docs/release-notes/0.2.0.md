# Companion 0.2.0

The first packaged macOS release of Companion.

- Run Companion from the menu bar with a bundled Node.js runtime.
- Open the dashboard, settings and logs from the menu bar.
- Control launch at login and automatic updates from Settings.
- Use Herdr Face, CodexBar, HEY, Clock, Roon and Attention on your display.
- Customise module layouts, animations and device colours in the Designer.
- Connect through automatic USB detection or choose a serial port.
- Extend hardware support through board profiles and the contributor guide.

Requires an Apple silicon Mac running macOS 13.5 or later. The tested device is the Waveshare ESP32-S3-Touch-AMOLED-1.75-B with Companion firmware installed. Other ESP32-S3 boards need a port; downloading the app does not flash firmware.

Integrations use their own installed tools or services. The app does not include HEY CLI, CodexBar CLI, Herdr or Roon.

Download the DMG, open it and drag Companion to Applications. The app runs in the menu bar. Open Dashboard to configure your device.
