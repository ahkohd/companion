# Companion 0.2.9

- Add Spotify, Apple Music and macOS Now Playing alongside Roon, with shared playback controls and artwork.
- Keep the previous track visible while skipping between tracks.
- Add audio input and output controls with a paginated device picker.
- Improve device picker typography and return to the audio controls after leaving the module.
- Improve physical touch handling so horizontal swipes switch modules and taps cycle agents.

The touch improvements require the updated device firmware; updating the Mac app alone does not install firmware.
